# Relatórios de estoque

Pasta oficial dos PDFs originais das avaliações de estoque em câmara fria do VITRA. Não adicionar relatórios de acompanhamento de área aqui.

## Regra obrigatória para arquivos com nome genérico

**Antes de enviar para esta pasta**, encaminhe o PDF no chat do projeto VITRA. O assistente irá:

1. Conferir no documento a **data da avaliação**, o **número de identificação do relatório**, o **produtor ou área** e o(s) **lote(s)**.
2. Verificar se já existe arquivo de mesmo nome e se a avaliação já está cadastrada, para evitar sobrescrita e duplicidade.
3. Informar o **nome exclusivo exato** para o usuário renomear **antes de publicar no GitHub**.
4. Após o envio, verificar a presença e integridade do PDF e vincular apenas os relatórios novos ao VITRA.

**Atenção — nome técnico, não nome de exibição:** a padronização abaixo vale **somente para o arquivo armazenado no GitHub e seu vínculo de PDF**. No VITRA, manter os nomes habituais de produtor/área e variedade e a identificação por data, lote e resultado. Nunca mostrar esse nome técnico como título da avaliação nem modificar resultados, classificações ou histórico por causa de uma renomeação.

**Padrão dos nomes genéricos:**

`ESTOQUE_AAAA-MM-DD_DOC_NUMERODORELATORIO_LOTE_NUMERODOLOTE.pdf`

Exemplo: `ESTOQUE_2026-10-22_DOC_92956762_LOTE_28189.pdf`.

Para relatórios com dois ou mais lotes, preservar os números dos lotes no nome sugerido e no cadastro, sem inventar medições específicas por lote que não estejam no original.

Documentos que chegam com nome automático exclusivo do Clicq podem conservar o nome original, após verificação de identidade.

**Nunca substitua um PDF existente para usar o mesmo nome.** Não exclua ou renomeie documentos antigos para abrir espaço: qualquer alteração em arquivo publicado depende de atualizar e verificar os links no VITRA.

O prefixo `FOR.CQ.068` identifica somente o formulário, não a avaliação. Se faltar identificação essencial, o assistente deve destacar essa ausência e propor uma solução segura, nunca inventar informações.

A referência integral dessas regras está no [README principal](../../README.md).
